PULLEY BLOCK INSPECTION ASSISTANT — GITHUB PAGES UPLOAD

1. Extract this ZIP on your computer.
2. Create a public GitHub repository named pulley-block-assistant.
   Add a README when creating it.
3. In the repository, choose Add file > Upload files.
4. Upload index.html from this folder (not the ZIP and not its enclosing folder).
   The optional .nojekyll file may also be uploaded. Commit the files to main.
5. Open Settings > Pages.
6. Set Source to Deploy from a branch, Branch to main, folder to /(root), Save.
7. When publication finishes, use Visit site on that settings page.

The app is self-contained in index.html. No software installation or build is needed.
The GitHub repository and website will be public. No inspection photos, drafts,
credentials, computer addresses or local hosting configuration are included.
Photographs and entered inspection data stay in the visitor's browser unless
explicitly downloaded as a draft or report. Closing/reloading loses unsaved work.

This is prototype v0.2.3. Independent engineering validation and physical-phone
verification remain outstanding. It does not issue a suitability approval or
replace the competent person's thorough examination or statutory report.
